BIN     MNE     2. word     3. word     DESCRIPTION
0000    NOP     -           -           No operation
0001    LDI     Immediate   -           Load Immediate to Accumulator
0010    ACC2R0  -           -           R0 <= ACC
0011    ADDI    Immediate   -           Add Immediate to Accumulator
0100    STA     MEM[7:4]    MEM[3:0]    Store Accumulator to Memory
0101    LDA     MEM[7:4]    MEM[3:0]    Load Accumulator from Memory
0110    SUBI    Immediate   -           Subtract Immediate from Accumulator
0111    JMP     MEM[7:4]    MEM[3:0]    Jump to MEM[7:0]
1000    JZ      MEM[7:4]    MEM[3:0]    Jump if Accumulator is Zero
1001    R02ACC  -           -           R0 => ACC
1010    CMPI    Immediate   -           Compare Immediate with Accumulator, sets flags without changing Accumulator
1011    CALL    MEM[7:4]    MEM[3:0]    Jump to MEM[7:0] and save following PC to RET_PC
1100    RET     -           -           Return from Subroutine to address in RET_PC
1101    LDMAR   Immediate   -           MAR[7:4] ← imm4, MAR[3:0] ← ACC, used for indirect addressing
1110    STA_MAR -           -           Store ACC at MEM[MAR] (indirect addressing)
1111    LDA_MAR -           -           Load from MEM[MAR] to ACC (indirect addressing)

1100 0000 -  1111 1111 192-255: Memory-mapped I/O

CONTROL SIGNALS
Label           Description
----------------------------------------
TEMP_LO_load    Enable loading low byte to LO_TEMP register
TEMP_HI_load    Enable loading high byte to HI_TEMP register
ALUTMP_load     Enable loading to ALU temporary register
RD_en           Enable read operation from memory
WR_en           Enable write operation to memory
PC_L_en         Enable loading low byte from LO_TEMP to Program Counter
PC_H_en         Enable loading high byte from HI_TEMP to Program Counter
UNUSED          UNUSED

ADDRBUS_sel     Select address bus source (0=PC, 1=MAR)
ALU_op0         ALU operation select bit 0
ALU_op1         ALU operation select bit 1
00 = ADD, 01 = SUB
BUS_sel0        Bus select bit 0
BUS_sel1        Bus select bit 1
BUS_sel2        Bus select bit 2
000 = DBUS_in, 001 = R0, 010 = ACC, 011 = ALU
100 = TEMP_lo, 101 = TEMP_hi, 110 = RET_LO, 111 = RET_HI
IR_load         Instruction Register load enable
ACC_load        ACC load enable

MAR_L           Memory Address Register low nible load enable
PC_src          This signal needs to be enabled to write LOW or HIGH nible from temp register.
PC_inc          While enable PC increments by one on edge
FLAGS_en        Loads signals from ALU to FLAGS
RET_PC_en       Load value from PC to RET_PC (used fro CALL -> RET)
µPC_sel0
µPC_sel1
µPC_sel[1:0]
00 = Increment by one
01 = DispatchROM[IR]
10 = Fetc aka 00000000
11 = IF NOT ZERO increment by 4 (JZ)
MAR_H           Memory Address Register high nible load enable
